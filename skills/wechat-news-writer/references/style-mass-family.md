# Style: mass_family

适用于家庭教育、亲子关系、婚姻代际、生活判断、情绪共识、下沉市场传播，以及中老年、县城乡镇、基层家庭读者场景。

## 目标读者

- 中老年读者
- 县城、乡镇、农村读者
- 家庭教育、亲子关系、婚姻代际话题的泛人群
- 更习惯口语表达、生活例子、直接判断的读者

## 内容目标

- 一眼能懂
- 立刻有代入感
- 读者很快知道“这篇是在替我把话说透”

## 工作原则

### 1. 先抓住读者最容易共鸣的那一下

优先从用户给的信息里找出：

- 最容易让普通家庭产生代入感的场景
- 最容易被读者认同或反驳的判断
- 最适合先说透的误区、委屈、焦虑或生活经验

### 2. 补充资料时，优先服务“说得明白”

这个风格也必须补充网络信息，但优先级和 `news` 不同：

- 先补足能支撑判断的真实案例、公开事实、政策背景、人物关系背景
- 再补足必要数据，不要为了显得专业硬堆数字
- 只引用真正能帮助普通读者听懂的资料

搜索时特别注意：

- 不要把复杂资料生硬搬进正文
- 不要为了查资料把语言写成报告
- 如果信息存在争议，正文里直接用更稳妥、更口语的说法化开

## 写法要求

- 结论可以更早出现
- 场景、例子、人物关系要更具体
- 语言更口语、更直接
- 多用日常表达，少用分析框架感
- 不是追求高级感，而是追求读者立刻听懂

## 贴近高阅读下沉稿的内容要求

- 优先像“把一句生活判断说透”，不要先像“解释一个概念”
- 第一屏就要让读者知道你站在哪一边，你在替谁说话
- 与其写“人脉的本质是资源交换”，不如写“你没坐到那个位置，人家跟你再熟，也未必真帮你”
- 与其写抽象结论，不如写普通人听得懂、转头能复述给别人的话

## 去分析感要求

- 少用“本质上”“某种意义上”“这意味着什么”“背后逻辑是”这类分析腔
- 少用“价值、资源、路径、结构、机制、半径”这类抽象词连续堆叠
- 如果一个意思能用生活话说清，就不要用概念话再包装一遍
- 不要把文章写成“观点说明书”，而要写成“把现实说破”

## 标题倾向

标题可以更像一句完整判断。

允许：

- 强对比
- 强判断
- 强代入
- 生活化句式

例如这种方向是合理的：

- “很多父母都搞错了……”
- “你以为……其实……”
- “真正让孩子吃亏的，不是……”

但要注意：

- 不要低俗夸张
- 不要恐吓式标题党
- 不要一句话塞太多抽象词

## 首段写法

- 开头先给读者熟悉场景、典型误区或直接判断
- 第一段最好让读者一眼明白：这篇在说我身边的事
- 不要先交代宏大背景
- 不要先做行业分析式铺垫
- 最好第一句就能单独拎出来成立
- 开头优先顺序是：判断、误区、委屈、处境，其次才是解释
- 不要一上来定义概念，先把读者最熟悉的现实说出来

## 小标题写法

小标题可以更像“把话说透”的判断句，但仍要克制。

优先这些类型：

- 误区点破型
- 生活判断型
- 场景拆解型
- 关系说明型

可以比 `news` 风格更口语，但不要写成喊口号。

## 段落与节奏

- 段落短，句子也可以更短
- 一段一个点，不要绕
- 可以适度重复关键词，帮助中老年读者跟住节奏
- 节奏上更强调“先认同，再解释”
- 允许一句话单独成段，尤其是判断句、转折句、提醒句
- 允许同一个核心词在前后几段里重复出现，不用刻意避重复
- 优先用“说一句，再补一句，再落一句”的节奏，不要一段里装太多意思

## 内容组织建议

- 更接近这种推进方式：先下判断，再说为什么很多人会误会，再说普通人真正会吃亏在哪里，最后落到该记住的那句话
- 不要求每篇都规整分成“定义、分析、结论”
- 比起完整论证，更重要的是一路让读者觉得“对，就是这么回事”

## Blocks 规范

优先使用这些 block 类型：

- `paragraph`
- `heading`
- `statement`
- `image`
- `numbered_list`
- `note`

谨慎使用：

- `quote`
- `pseudo_table`

默认不要输出：

- 原生 `table`
- `bullet_list`
- 空白占位块
- 大段内联 CSS

这个风格里，block 的目标不是“显得结构化”，而是“让读者更顺着往下看”。

### `paragraph`

这是最核心的 block。优先靠普通段落推进，不要过度依赖块状组件。

允许使用 `segments`，但要更克制，优先突出关系判断、误区点和结果。

补充要求：

- 段落里优先出现具体人、具体身份、具体处境
- 少写空泛判断，多写“谁会这样想、谁会吃这个亏、现实里会发生什么”
- 如果一句话已经够重，就不要后面再跟一串解释把劲儿卸掉

推荐变体：

- `lead`
- `body`

### `heading`

可以更口语、更像“把话说透”的一句判断，但不要像喊口号。

推荐变体：

- `judgement_heading`

推荐格式：

```json
{ "type": "heading", "variant": "judgement_heading", "text": "巴结和讨好，换不来真正的人脉" }
```

补充要求：

- 小标题最好像一句完整的人话，而不是章节标签
- 优先让读者一眼就明白这一段要说什么，不要写成抽象概括

### `statement`

这是这个风格的专属 block。用于把一句最值得停下来的判断单独拎出来，但不要做成“鸡汤金句卡”。

适合场景：

- 一句话点破误区
- 一句话说透关系本质
- 一句话承接上下文转折

推荐变体：

- `centered_statement`

推荐格式：

```json
{ "type": "statement", "variant": "centered_statement", "text": "人脉的本质是价值交换，不是单方面索取。" }
```

### `note`

只用来提醒读者那些平时最容易忽略、但现实里很容易吃亏的小地方。

硬约束：

- 必须是面向读者的生活提醒
- 不要像老师批改作文
- 不要写创作者提示

推荐变体：

- `gentle_note`

### `numbered_list`

适合拆解“3个误区”“4种情况”“几句话说透一个道理”这类内容。

### `quote`

只有当一句话确实像“这一篇最该记住的话”时才用。默认少用。

### `pseudo_table`

除非内容场景必须，否则不要刻意使用表格、请谨慎使用它。

### `image`

正文图片必须直接放在 `blocks` 中，用顺序表达位置。

硬约束：

- `image_url` 优先使用 `jpg`、`jpeg`、`png`、`webp`
- 不要使用 `svg`
- 不要用 logo、图标、透明底装饰图替代正文配图
- 优先选择中国语境下的人物、家庭、生活、教育相关场景图
- 优先出现中国家庭、中国家居、中国学校、中国社区、中国县城/乡镇、中国城市街景等真实生活环境
- 尽量避免欧美面孔、欧美家居、欧美校园、欧美街景这类一眼偏国外语境的图片
- 搜图关键词应优先带中国语境限定，例如“中国 家庭”“中国 家长 孩子”“中国 学校 家长会”“县城 生活”“乡镇 家庭”
- 只要返回 `image` block，就强烈建议同时返回 `source_name` 和 `source_page`
- `source_name` 优先写真实来源主体，不要写“网络”“AI生成”“示意图”

推荐变体：

- `scenario_media`

## 强调方式

`segments[].marks` 允许值固定为：

- `bold`
- `underline`
- `accent`

- `bold`：适合把一句话的判断钉住
- `underline`：适合划出读者容易忽略、但很关键的那半句
- `accent`：适合放在关系核心、误区点、结果、代价上

整篇规则：

- 同一段通常 1 到 2 处就够
- 单个高亮片段尽量短
- 不要把整段都打成重点
- 强调要服务“听懂”和“记住”
- 不要追求花哨的知识感强调
- 比起数字，更适合强调关系判断和后果
- 优先强调读者最容易记住、最容易转述给别人的那半句

## 主题色规则

- 不要在 JSON 中返回 `theme` 对象
- `mass_family` 风格的强调色由插件固定为 `#c14851`
- 写作时只需要决定哪些句子该用 `accent`，不要再生成颜色相关字段

## `note` 使用边界

`note` 只留给真正需要提醒读者的小细节，例如：

- 很多人平时容易忽略的一点
- 某种做法的边界
- 现实里最容易踩坑的地方

不要把 `note` 写成说教框，不要像老师批改作文。

## `quote` 使用边界

`quote` 在这个风格里应更少用。

只有当一句话确实像“整篇要记住的那一句”时才用。不要强行做金句卡。

## 图片策略

- 图片以中国人物、中国家庭场景、中国生活场景、中国教育场景为主
- 图片要让读者一眼知道“这篇讲的是哪类人、哪类事”
- 不要用过冷的产品图或纯信息图替代生活场景图
- 如果拿不准，宁可选中国本地媒体、学校、社区、家庭生活照片，也不要选明显是国外素材库风格的图

## 结尾

结尾优先：

- 给一个现实提醒
- 收到一句让读者带回家的话
- 落到家庭关系或实际做法上
- 最后一段最好让读者有“这话我得记住”或者“这话我想发给别人看”的感觉

不要空泛拔高，也不要突然变成大道理总结。

## 禁止项

- 不要写得像研究报告
- 不要大量出现“这意味着什么”“从某种意义上说”“本质上”
- 不要每一段都在分析趋势
- 不要故意显得高级

## 事实与风险控制

- 不编造案例、人物经历、数据或来源
- 如果涉及政策、学校、医疗、法律等现实风险点，必须用稳妥说法
- 不要为了煽动情绪把不确定信息写成肯定事实
- 能说清楚就说清楚，不要为了“像大白话”牺牲真实性

这个风格的核心不是“显得聪明”，而是“让读者觉得你说的是人话，而且说到了心里”。
