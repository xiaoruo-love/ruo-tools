公众号 Blocks 设计稿预览

这个页面按当前 wechat-publisher-bridge.js 的真实样式映射制作。现在的方向不是“做出组件感”，而是尽量贴近真人会发的公众号正文。它不是新的视觉提案，而是让你快速看到每种 block 在最终文章中的落点和层次。

  • 段落：`lead` / `body` / `analysis`
  • 标题：`section_title` / `section_title_strong`
  • 提示：`insight_box` / `warning_soft`
  • 数据强调：`data_point`
  • 表格：`compare_grid` / `fact_sheet`
  • 图片：正文图 + 底部来源提示

Theme

每篇文章先生成一套主题色，再统一驱动强调样式

冷静灰蓝 · #6c7b95 适合规则解读、产品观察、信息整理类文章

主题色不应该是固定模板色，而应该由 AI 根据文章题材决定，再统一作用到分节引导、轻提醒前缀和正文内联强调上。

  • 推荐：灰蓝、灰棕、灰绿、酒红、青灰这类低饱和颜色。
  • 避免：荧光绿、亮紫、玫红、纯橙、饱和宝蓝这类高刺激颜色。
  • 默认一篇文章只保留 1 个主强调色，不做多色拼贴。

    "accent_name": "冷静灰蓝",
    "reason": "适合规则解读、产品观察类内容"
  }
}

完整文章效果

微信把“单删互删”讲透了，但真正刺痛人的不是规则

6月26日，微信官方账号“微信派”发布《几个关于朋友圈的冷知识》，终于把很多人争论已久的两个问题讲明白了。

如果只看结论很简单：单删，互动通常还在；互删，对方痕迹才会消失。但真正值得讨论的，是微信为什么始终把“关系结束”处理得比人的情绪慢半拍。

Part 01
先看最关键的规则：单删和互删，结果完全不一样

场景

互动会不会消失

补充说明

单删

不会

历史点赞评论通常保留，对方未必察觉

互删后重加

会恢复

过去互动可原样归位

删好友在人的直觉里像一刀切断，但在微信的系统逻辑里，它更像先收回权限，再慢慢处理痕迹。这也是为什么很多人看到规则说明后，真正难受的并不是功能本身，而是那种关系没有被系统立即清零的滞后感。

一个经常被忽略的细节

单删状态下，你依然可以回复对方以前留在朋友圈里的评论，只不过这条回复更像一个只对自己可见的记录。直到双方重新加回好友，它才会重新回到对方视野里。这种设计很微信：它不急着把一段关系彻底抹平，而是把很多痕迹先悬在那里。

（图片来源：wechat.com）

提醒：如果你真的在意朋友圈可见范围，新增好友后应及时调整分组，否则旧设置不会自动覆盖新关系。

从这个角度看，朋友圈规则讲的从来不只是技术细节。它真正影响的是，人在处理熟人关系时，到底还能不能保留一点缓冲地带。对很多用户来说，刺痛感并不来自规则本身，而是来自微信把那些原本以为已经结束的痕迹，又悄悄留在了原地。
