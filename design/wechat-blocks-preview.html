`lead` / `body` / `analysis`

6月26日，微信官方首次把朋友圈互动留存规则讲得这么直白：单删不清痕迹，互删才会让对方点赞评论消失。

这不是一个只影响“删好友”的小功能，而是在重新定义微信怎样处理熟人关系的历史记录。

从产品逻辑看，微信并没有把“删除好友”理解成“关系痕迹立即归零”，而是保留了一个更缓慢的社交过渡层。

Note

`insight_box` / `warning_soft`

一个关键细节是：单删状态下，你仍然可以回复对方旧评论，但那条回复在重新加回好友前只对你自己可见。

如果你真的在意朋友圈可见范围，新增好友后应尽快调整分组，否则旧设置不会自动套用到新关系上。

Bullet List

适合重点并列、规则拆解、行动建议

  • • 单方面删除好友，历史点赞和评论通常仍然保留，不会立刻消失。
  • • 双方互删后，对方留在你朋友圈的互动痕迹才会被隐藏。
  • • 如果后来重新加回好友，过去消失的互动仍有可能原样恢复。 
{
  "type": "bullet_list",
  "variant": "key_points",
  "items": [
    "单方面删除好友，历史点赞和评论通常仍然保留，不会立刻消失。",
    "双方互删后，对方留在你朋友圈的互动痕迹才会被隐藏。",
    "如果后来重新加回好友，过去消失的互动仍有可能原样恢复。"
  ]
}

Numbered List

适合步骤、排序、递进结构

  • 1 先确认这是单删还是互删，因为两种状态的互动留存逻辑完全不同。
  • 2 再看朋友圈分组是否已更新，新加好友默认不会自动继承你过去的屏蔽意图。
  • 3 最后再判断这是不是功能 bug，很多时候只是微信规则和直觉不一致。

微信把“单删互删”讲透了，但真正刺痛人的不是规则

6月26日，微信官方账号“微信派”发布《几个关于朋友圈的冷知识》，终于把很多人争论已久的两个问题讲明白了。

如果只看结论很简单：单删，互动通常还在；互删，对方痕迹才会消失。但真正值得讨论的，是微信为什么始终把“关系结束”处理得比人的情绪慢半拍。

先看最关键的规则：单删和互删，结果完全不一样

删好友在人的直觉里像一刀切断，但在微信的系统逻辑里，它更像先收回权限，再慢慢处理痕迹。
